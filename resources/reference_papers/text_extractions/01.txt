For the multi-UAV game missions, intelligent agents face challenges in high-dimensional state processing, dy-
namic situational awareness, and cooperative decision-making that conventional methods cannot address eﬀec-
tively. This paper proposes a novel Large Language Model-enhanced Multi-agent Deep Reinforcement Learning 
scheme (LLM-MATD3) with a hierarchical decision-making architecture comprising an environment modeling 
layer, LLM task planner, and task-enhanced MATD3 network. The scheme ﬁrst employs a hierarchical task decom-
position mechanism that transforms high-level game directives from LLMs into continuous embedding vectors 
through task embedding techniques. Then, the LLM task planner analyzes global game situations and assigns 
diﬀerentiated tasks to UAVs, overcoming the limitation of traditional MATD3 frameworks that rely solely on 
local observations. Simulation results show signiﬁcant improvements in win rate, remaining rate, and collabo-
rative eﬃciency  for UAVs, providing a innovative reference approach for multi-agent systems in complex game 
environments.
1.  Introduction
Recently, rapid advances in Unmanned Aerial Vehicle (UAV) tech-
nology have emerged in aerospace ﬁeld, and the performances of au-
tonomous ﬂight control and collaborative decision-making in complex 
environments directly determine the systems’ comprehensive capabil-
ity [1]. Modern UAV systems face numerous technical challenges, with 
actuator fault and anti-disturbance control issues being particularly 
prominent, requiring intelligent tracking control strategies for ﬂight 
safety [2]. Moreover, modern electromagnetic environments, charac-
terized by strong electromagnetic pulses and intentional interference, 
severely impact UAVs’ sensor modules and communication links [3]. 
In highly dynamic aerial game scenarios, external disturbances includ-
ing gusts and turbulence continuously threaten ﬂight stability, where 
integrating ﬁxed-time observers with sliding mode control provides an 
eﬀective solution [4]. However, the challenges of real-time cooperative 
decision-making, dynamic task allocation, and intelligent game strate-
gies become critical problems when multiple UAVs work collaboratively 
in such complex game environments.
Multi-UAV cooperative systems enhance operational eﬀectiveness 
through distributed architectures. For example, context-aware feature

methods like QMIX [24] and QTRAN [25] enable coordination but 
assume discrete action spaces. Recent advances show mixed results: 
it should be noted that some integrated results has been presented. 
For example, MAHPG [26] achieves policy diversity but scales poorly

the gap between theoretical advances and practical multi-UAV deploy-

On the other hand, the breakthrough advances in Large Language 
Models (LLMs) oﬀer novel solutions to address the mentioned limita-
tions [29]. LLMs possess robust capabilities in contextual understanding, 
logical reasoning, and knowledge synthesis, enabling task comprehen-
sion from high-level semantic perspectives to global policy generation. 
Notably, LLMs oﬀer advantages over rule-based methods through con-
textual reasoning and adaptive strategy generation in complex game 
scenarios. Recent studies demonstrate that integrating LLMs with rein-
forcement learning signiﬁcantly enhances sample eﬃciency  and gen-
eralization capabilities [30]. Zhu et al. proposed the LAMARL frame-
work [31], which leverages LLMs to automatically generate prior poli-
cies and reward functions for MARL, achieving cooperative policy gen-
eration without manual design while signiﬁcantly improving sample ef-
ﬁciency through prior policy integration. Liu et al. introduced the LGPF 
framework [32], utilizing LLMs’ few-shot generalization to transform 
natural language descriptions into formation patterns, combined with 
CTDE architecture for precise swarm robotics control. However, it is also 
an open problem to eﬀectively integrate LLMs’ high-level cognitive ca-
pabilities with MARL’s real-time decision-making abilities, particularly 
in highly dynamic and aerial game environments.
It should be noted that the existing approaches for multi-UAV game 
decision-making still suﬀer from three following limitations: (1) tradi-
tional RL frameworks (such as MATD3) rely solely on local observa-
tions without global situational awareness [33]; (2) a semantic gap ex-
ists between LLM-generated high-level directives and continuous policy 
learning in reinforcement learning [31,32]; (3) an eﬀective integration 
mechanism between LLMs’ cognitive reasoning and MARL’s real-time 
decision-making remains absent [34]. To solve the above limitations, 
this work proposes a LLM-MATD3 scheme that constructs a hierarchical 
decision-making framework bridging global game planning and local 
execution through LLM-MARL integration. The main contributions in-
clude:
(1) A large language model-based game analysis and task planning 
framework is proposed to comprehensively analyze complex game 
situations and assign task types to each UAV, enabling hierarchical 
decision-making control from macro game perspectives to micro 
execution.
(2) A hierarchical task decomposition mechanism is proposed, whereby 
a specialized game reward function decomposes abstract task labels 
into state-dependent continuous subgoal completion scores. It en-
hances the semantic expressiveness of task embeddings, enabling 
the transformation from discrete task assignments to continuous be-
havioral guidance.
(3) A task-aware Actor-Critic network structure is proposed that inte-
grates enhanced task embeddings into both policy and value net-
works. The actor network generates task-conditioned actions by 
combining state observations with task-speciﬁc guidance, while 
the critic network learns task-dependent value functions that ac-
count for task label transitions. It also enables an adaptive decision-
making performance across diverse task types.

3.  LLM-enhanced MATD3 framework and methods
In view of the existing LLM-enhanced reinforcement learning meth-
ods, they typically provide one-time guidance during pre-training or 
cold-start phases, such as LLM-guided exploration [34], prior policy gen-
eration [36], formation pattern description [37], and action distribution 
guidance [38]. Compared with the above results, the proposed LLM-
MATD3 continuously integrates LLM instructions into the Actor-Critic 
network through the hierarchical task embedding mechanism, enabling 
real-time policy modulation across multi-agent coordination, continu-
ous action spaces, and dynamic task allocation in game scenarios. In 
this section, we will present a novel LLM-enhanced MATD3 framework 
that integrates the game planning capabilities of large language models 
with the autonomous decision-making of deep reinforcement learning. 
As shown in Fig. 3, the framework comprises four components: the en-
vironment modeling layer, the LLM task planner, the task embedding 
network, and the task-enhanced MATD3 network. The LLM task planner 
analyzes situational dynamics and assigns speciﬁc tasks to each agent. 
Subsequently, the hierarchical task decomposition mechanism, guided 
by a specialized task game reward function, transforms abstract task 
labels into enhanced embedding vectors. These embeddings provide se-
mantic guidance for reinforcement learning-based action generation.

4.2.2.  Task allocation eﬀectiveness
This section evaluates the eﬀectiveness of LLM-based task allocation 
by comparing it with ﬁxed allocation methods and analyzing the im-
pact of allocation ratios. Fig. 8(a) presents execution success rates across 
three task types, with each data point representing the average of 100 in-
dependent simulation runs. LLM allocation outperforms ﬁxed allocation 
in active tracking (80.5% vs. 63.2%) and cooperative support (46.4% vs. 
31.6%) tasks. Notably, ﬁxed allocation outperforms LLM allocation in 
area defense tasks (60.5% vs 48.7%), likely because predeﬁned posi-
tions reduce coordination uncertainty. It should be noted that the area 
defense task is fundamentally a position-maintenance task where execu-
tion depends on local motion control rather than high-level reasoning, 
and ﬁxed allocation provides more uniform spatial coverage compared 
to LLM’s dynamic reallocation which may create temporary coverage 
gaps.
Fig. 8(b) compares win rates and exchange ratios across six task al-
location conﬁgurations, where the ratio denotes Active Tracking : Area 
Defense : Support. Each conﬁguration is evaluated over 100 Monte Carlo 
simulations. The results reveal a non-monotonic performance proﬁle: 
the optimal 55:35:10 conﬁguration achieves an 82.0% win rate and 2.59 
exchange ratio while minimizing variance. Performance degrades when 
active tracking exceeds 70%, indicating that balanced task allocation is 
critical for overall eﬀectiveness. Moreover, the box plot distributions in-
dicate that the 55:35:10 conﬁguration exhibits the smallest box height, 
reﬂecting superior stability across 100 simulations. Conﬁgurations with 
extreme ratios, such as 30:40:30 and 70:20:10, display wider boxes and 
greater variability. The isolated circle points beyond the box plots in 
Fig. 8(b) represent a few simulation runs with results notably diﬀerent 
from the majority. The combination of highest mean performance and 
lowest variance conﬁrms 55:35:10 as the most robust allocation results.

4.4.  Visual analysis
To validate the practical eﬀectiveness of LLM-MATD3, this section 
presents a visual analysis of two representative formation strategies in 
5v5 game scenarios.
As shown in Fig. 10, The LLM recommends concentrated formation 
based on situational assessment. During the initial phase (𝑡 = 0 − 80 ), 
Team A UAVs converge into a tight coordination. In the mid-phase 
(𝑡 = 160–300), agents executing active tracking (𝜏 = 0) form a semicir-
cular encirclement, constraining Team B to the central region. By the 
terminal phase (𝑡 = 400), Team A achieves complete elimination with 
minimal losses, demonstrating superior concentration and breakthrough 
capability.
As shown in Fig. 11, the LLM recommends a scattered formation 
strategy. Team A UAVs adopt dispersed initial positions to minimize 
concentrated damage. In the middle phase (𝑡 = 160 − 300 ), they engage 
from multiple angles, fragmenting Team B’s defensive formation. Al-
though UAV ID:7 gets damaged (Heath State:76), Team A maintains 
the advantage through ﬂexible repositioning. The victory with only one 
damaged UAV demonstrates that scattered formations eﬀectively bal-
ance multi-directional engagement with survivability.
In summary, concentrated formations provide superior game den-
sity, making them suitable for scenarios with clear force advantages 
or rapid breakthrough requirements. Scattered formations oﬀer better 
spatial coverage and survivability against uncertain conditions. LLM-
MATD3 dynamically selects formations based on real-time conditions, 
demonstrating adaptive decision-making in complex task environments.
5.  Conclusion
This work proposes a Large Language Model-enhanced multi-agent 
deep reinforcement learning scheme(LLM-MATD3) for task decision-
making. Through systematic simulation experiments, we demonstrate 
its eﬀectiveness in multi-agent decision-making domains. The hierarchi-
cal task decomposition mechanism transforms abstract task labels into 
state-dependent sub-goal scores, eﬀectively integrating LLM guidance 
with autonomous decision-making. This approach enhances collabora-
tive capabilities in high-dimensional state spaces. Further analysis re-
veals that semantic enhancement and task decomposition mechanisms 
reduce decision space complexity, eﬀectively addressing the curse of 
dimensionality problem. Additionally, dynamic task allocation enables 
agents to adjust execution modes based on game dynamics. In the fu-
ture, we will further explore deep integration of LLM with reinforcement 
learning under game learning frameworks, hybrid dynamic-static task 
allocation strategies across diverse task types, multi-modal situational 
awareness with decision composition, and lightweight deployment so-
lutions in continuous computing environments.
