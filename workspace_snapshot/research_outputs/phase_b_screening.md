# 阶段 B 筛选报告：指令级修改的真实价值与可预测性

日期：2026-10-13
数据：experiments/critic_advice/runs/screen40/（40 种子 × 每局 ~29 个决策点 × 每点适用编辑，4343 对有效配对；另有 runs/screen40_ep/ 整局窗口版）
代码：experiments/critic_advice/{harness,edits,collect_pairs,analyze_pairs,predict_gain}.py（版本哈希见各 run 的 config.json）
结论范围声明：本轮**未接入真实 LLM**（容器与宿主机均无外网，阶段 C 不可达）；结论限定为"冻结 actor + H 启发式下的修改价值结构与可预测性"，不构成"反馈改善大模型决策"的证据。

## 1. 实验设计（登记于运行前）

- 配置：100×100、4 机、3 火点、10 人、600 步、重规划周期 20；H = HeuristicBrain(charge_at=260, explore_until=0.70, max_chargers=2)；actor_best.pt 确定性执行。
- 配对协议：同一快照（deepcopy + 三套 RNG 状态）分叉；分支 B 只在**本段**替换计划，之后恢复与分支 A 完全相同的 H 协议。测的是"一次局部修改在同一状态、同一后续控制协议下的真实任务收益差"。
- 主要配对指标（登记）：Δ过火格数、Δ扑灭格数 @ +20 / +60；护栏：Δ覆盖率均值、Δ耗尽数、Δ探索率、Δ人员已知、Δ最低电量。
- 删失口径：任一分支提前 done 时 steps_run 不一致，单列不入均值（实际 0 条）。
- 确定性验证：240 条 noop 检查（原计划重发），全部指标完全零差 → 配对差可精确归因于计划本身。

## 2. 编辑目录与触发频率（40 种子，1160 个决策点）

| 编辑 | 语义 | 触发 n | 说明 |
|---|---|---|---|
| rule_relay_uncovered | 存在"未覆盖且无人认领"人员且中继<2 → 就近机补中继 | 373 | H 中早期只留 1 台中继，是主要候选瓶颈 |
| rule_redundant_relay | 无覆盖缺口且中继≥2 → 释放 AoI 最低中继 | 131 | 瞬时覆盖判据的反面教材 |
| rule_explore_redirect | 搜寻机目标重定向到最远象限 | 1198 | 高频但低响应 |
| rule_charge_lowest | 非充电机余量<120 → 补给 | **1** | H 的能量管理已覆盖该基准的全部余量区间 |
| rule_relay_return_fix | 中继机余量<0 → 补给+接替 | **0** | 同上 |
| rule_patrol_dedupe / rule_ring_auto | 巡逻去重 / 环半径回 auto | 0 / 0 | H 的巡逻绑定不重复、环半径恒 auto |
| ctrl_random_edit | 随机合理编辑（对照） | 2400 | "随机修改"基线 |

**发现 B1（H 无电量/巡逻瓶颈）**：charge/return-fix/dedupe/ring 规则几乎不触发。H 的返航阈值（charge_at=260 + 名额 2）与巡逻分配在该基准下没有留下可检出的执行瓶颈。可重复瓶颈集中在**通信覆盖**（relay_uncovered 373 次触发）。

## 3. 平均效应：没有任何规则编辑在均值上击败 H（40 种子，按种子聚类 95% CI）

| 编辑 | n | Δ扑灭@20 | Δ扑灭@60 | 零响应@20 |
|---|---|---|---|---|
| ctrl_random_edit | 2273 | −0.04±0.08 | −0.19±0.31 | 842/2273 (37%) |
| rule_explore_redirect | 1198 | −0.04±0.06 | −0.29±0.22 | 773/1198 (64.5%) |
| rule_redundant_relay | 131 | +0.05±0.30 | −0.50±1.99 | 22/131 |
| rule_relay_uncovered | 373 | +0.02±0.23 | −0.06±1.00 | 48/373 (12.9%) |

**发现 B2（H 平均近优）**：全部均值 ≤ 0 且 CI 跨零。策略含义：任何"总是应用某规则"的反馈机制在此基准常规场景没有平均收益空间（指南 §11 预期了这一情况）。

**发现 B3（瞬时判据误导）**：rule_redundant_relay 按"当前无覆盖缺口"释放中继，Δ覆盖率@60 −0.055±0.028、Δ扑灭 −0.50——瞬时 coverage 高不等于可以撤中继（AoI 是存量指标，撤了就涨）。

**发现 B4（指令-响应严重不对称）**：explore 目标重定向 64.5% 在 20 步内零执行响应（Actor 对远距离搜寻目标的跟随弱）；relay 编辑只有 12.9% 零响应。给 LLM 的建议若不区分"底层会响应什么"，一半以上是无效指令——量化证实指南事实 #10。

## 4. 分布与个案：效应存在双尾 ±35~62 格，机制可解释

Δext@60 分布：p50=0、p90=+4、p99=+26、max=+35、min=−41。大效应个案的机制叙事（中间指标链）：

| 案例 | 编辑 | Δrknown@60 | Δext@60 | 机制 |
|---|---|---|---|---|
| s30008 t=0 | 补中继#2 | +0.233 | +35 | 中继→人员知情→灭火，教科书式正路径 |
| s30003 t=220 | 补中继#9 | +0.169 | +35 | 同上（尽管 Δcov@60 为负） |
| s30000 t=200 | 补中继#8 | **−0.371** | **−32** | 转岗机原在顺路喂知识；全队策略输入随之改变，净效应为负 |
| s30036 t=120 | 补中继#8 | +0.334 | **−41** | Δcov@20 +0.20（机制先兑现）但 @60 反转 |
| s30008 t=220 | 重定向搜寻机 | −0.254 | **−62** | 搜寻机顺路覆盖多人；拉走即断粮 |

**发现 B5（"局部编辑"在效果空间不局部）**：底层是参数共享策略，每架机的观测含全队任务构成（obs_builder coord 特征），改一架的任务标签会让**全部四架的策略输入同时改变**——所有轨迹立即分叉。加上信息融合规则（无人机路过人员即融合地图），一个"补中继"编辑的净效应由多条通道相加而成，可正可负。
**发现 B6（覆盖无多跳链）**：人员覆盖 = 与任一无人机/基站的直接几何邻接（Env/低层环境.py:1692-1741），不存在无人机间转接链；"链桥"解释不成立，耦合来自策略观测与顺路信息融合。

## 5. 可预测性：任务层不可测，机制层半可测

按种子切分（28/4/8），45 维可观测证据特征（态势 + 人员几何 + 编辑语义 + 机制量）：

| 目标 | test pearson | test spearman | 结论 |
|---|---|---|---|
| Δ扑灭@60（任务层） | **−0.086** | −0.073 | 不可测；标定箱无单调性 |
| Δ覆盖率均值@20（机制层） | **+0.536** | +0.334 | 半可测（relay 编辑的覆盖效应较机械） |
| Δ人员已知@20 | +0.135 | −0.042 | 弱 |

已实现的 @20 中间结果对 @60 任务收益的预测力（在线短窗分叉是否可当评估器）：

| 已实现@20 | vs Δext@60 pearson / spearman |
|---|---|
| Δcov20（仅 relay 编辑内） | +0.045（高分位组真实均值 −0.20 vs 其余 −0.03，无区分） |
| Δrknown20 | +0.096 / +0.318 |
| Δext20 | +0.298 / +0.398 |

**发现 B7（两级分解的下半段断裂）**："编辑前证据 → 机制收益@20"部分可行；"机制收益@20 → 任务收益@60"断裂（≤0.3）。任务层收益被 20-60 步之间的救援人员重分配级联主导，不是编辑语义的函数。oracle 上界 +1.74 扑灭格/决策点（240 点合计 +417）确实存在，但以当前特征与模型无法识别。

## 6. 整局窗口（600 步）鉴别实验（runs/screen40_ep，同键 3976 对）

- 整局尺度 noop 确定性仍成立（240 条检查全部零差——分叉后 500+ 步重放完全可复现）。
- **Δext@60 与 Δext@episode 相关性 = +0.008**（spearman +0.122）；|Δext@60|>10 的 231 条"大效应"里，与整局结果的**符号一致率仅 44.2%（低于抛硬币）**，全体 63.9%。60 步窗口的任务收益是瞬态噪声，还会均值回归；按短窗任务指标选编辑是在拟合噪声。
- Δext@episode 分布：p10=−5、p50=0、p90=+10、p99=+51、max=+112、min=−98、std=14——级联在整局尺度继续放大而非摊平。
- 分类型整局均值（按种子聚类 95% CI）：random +1.50±1.87、relay_uncovered +1.68±2.04、explore_redirect +0.66±1.56、redundant_relay −0.73±2.35——**全部 CI 跨零**。
- **唯一稳健的因果通道**：Δrknown@episode ↔ Δext@episode = **+0.469**（spearman +0.269）——人员知识转移是任务收益的真实通货；覆盖@episode 与扑灭无关（−0.03），说明起作用的不是"被覆盖"这个瞬时状态而是知识的持续传递。

**发现 B8（评估口径结论）**：单次编辑的价值必须用整局任务指标评估（短窗被噪声主导且反向）；而整局效应分布宽（std 14），单次建议无法承诺收益方向。若反馈机制有真实价值，只能来自**复合**（每个规划周期持续应用）后按多种子统计。→ 复合策略实验见 §7。

## 7. 复合策略实验：把建议固化为持续策略，整局按种子配对

单次编辑不可承诺任务收益（B7/B8）→ 部署形态的问题是复合：反馈机制每个规划周期都起作用。把候选建议固化为 H 的策略变体，同种子整局配对（确定性 actor → 精确配对差），n=40 种子（31000-31039），7 个策略（runs/policy_ep/results.json）：

| 策略 | 语义 | Δ扑灭/回合 | 配对 p |
|---|---|---|---|
| P1_relay2 | 始终 2 中继（= 每个决策点应用 relay_uncovered 建议） | **+6.20±5.60** | **0.031** |
| P4a_chargeat200 | 更晚充电 | +4.50±5.99 | 0.137（Δ最低电 **−111**，护栏破） |
| P2_explore85 | 探索期延长 | +2.52±4.37 | 0.250 |
| P3a/P3b/P4b | 充电名额/时机变体 | +1.0 / −0.7 / +1.2 | n.s. |

P1 是唯一方向为正且护栏干净的策略，但 p=0.031 过不了 7 重比较 Bonferroni（≈0.22）。按方法论做**预先登记的确认实验**：120 个全新种子（32000-32119）只跑 P0/P1：

- **P1 确认结果：Δext = −1.07±5.24（p≈0.69）——未复现。** 探索集的 +6.2 是假阳性（或种子族特异）。runs/policy_ep/confirm_P1.json

**发现 B9（复合策略同样无真实收益）**：7 个持续策略变体在整局尺度上没有可靠的任务收益；唯一 suggestive 的 P1 在 3 倍规模的新种子上复现失败。

## 8. 饱和诊断与适用范围（压力场景）

基线（P0）在基准配置下的绝对水平：扑灭 238 格、过火 475 格、合围 3.5/约 3.7 簇、覆盖均值 0.70、人员已知 0.80、探索 0.90、耗尽 0.0——**该基准已被 H+冻结 actor 基本解决**：发现率 1.0、绝大多数火点被合围，分配矛盾不紧张，反馈/建议没有可兑现的边际价值。这解释了 B2/B9 的全部零结果。

### 8.1 压力场景结果：建议价值随资源紧张度反转（runs/policy_ep/stress_*.json）

| 场景 | P0 基线（扑灭/合围/rknown） | P1_relay2 Δ扑灭 | Δ覆盖均值 |
|---|---|---|---|
| 基准（4 机/10 人/3 火）40 种子 | 238 / 3.5 / 0.80 | +6.20±5.60（p=0.031，未过校正） | +0.027 |
| 基准 120 新种子确认 | — | **−1.07±5.24（p=0.69）未复现** | — |
| 16 人/4 火/4 机，60 种子 | 316 / 4.6 / 0.77 | +1.97±5.64（p=0.49） | **+0.057（p<0.001）** |
| 18 人/4 火/**3 机**，60 种子 | （见 json） | **−10.50±12.84** | +0.09（Δrknown **−0.07**、Δ过火 **+14.7**） |

**发现 B10（建议价值随资源条件反转）**：
- 饱和 regime（4 机）：P1 的机制收益显著兑现（覆盖 +5.7pp, p<0.001）但任务收益为零——多出的覆盖没有转化为灭火增量（rknown 0.77 本就够用，瓶颈在物理灭火能力不在信息）。
- 稀缺 regime（3 机）：分配决策开始真正影响任务结果（±10 格量级），但**盲目持续建议有害**（扑灭 −10.5、过火 +14.7）：3 架机养不起 2 台专职中继，中继挤占感知导致发现/已知双降。
- 结论：建议空间里存在任务层差异真实的 regime；正确答案必须随资源状态条件变化（几机、多少未覆盖、多少活火、探索进度）。这是状态条件 Critic/Advisor 的真实价值所在，也是后续轮次（阶段 B 正式版 + 阶段 C）应在的实验域：**稀缺场景 + 机制层建议 + 整局任务验收**。

## 9. 阶段 B 结论与方向修正

1. **"哪条指令有问题"有可重复答案**：通信覆盖缺口（relay_uncovered 373/1160 决策点）是本基准下唯一高频的真实执行瓶颈类别；能量/巡逻类瓶颈不存在（B1）。
2. **"具体改什么"的候选空间有真实价值但双尾**：同一规则编辑 ±35 格两尾并存，均值恒 ≈0（B2）；收益方向由状态与级联共同决定；短窗"大收益"与整局结果负相关（44% 符号一致）。
3. **"依据是什么"的正确层级是机制层**：覆盖/已知/能量等中间量可测、可验证（Δcov20 pearson 0.54）；扑灭数等任务量在 60 步窗口不可承诺（B7），整局效应宽分布且被 rknown 通道主导（+0.47）。
4. **对论文主张的修正**：Critic 的"精确可操作建议"应交付——(a) 定位（哪机、哪指令、哪类瓶颈，证据为可观测谓词）；(b) 机制层预测收益（本段窗口内覆盖/已知/能量的变化，配对校准）；(c) 任务层的不确定性声明与拒答规则（不可验证的收益不承诺）。"用标量分数触发重规划"（ReAd 式）与"总是应用规则"都被数据否定为无平均收益；差异化主张落在**机制层的可验证承诺 + 校准**上。
5. **基准饱和是零结果的主因**（§8）：后续轮次必须先构造分配矛盾紧张的场景（更多人员/火点、更紧的能量），再检验反馈机制的边际价值；在该基准上继续调建议格式不会有收益。
6. **下一步**：(i) 压力场景下重跑筛选（§8.1 起步）；(ii) 机制层预测器的完整验收（校准曲线、拒答后的负收益建议率）；(iii) 若进入阶段 C：把建议格式化为指南 §5.2 的 JSON（confidence 用机制层校准值填充，predicted_gain 只报机制量）；(iv) 真实 LLM 需先恢复外网（容器与宿主均不可达）。
