# 研究工作区归档（2026-11-03）

本目录按原项目相对结构保存研究代码、文档与运行记录，尽量保留原始路径，便于追溯研究过程和复现实验。它是研究快照；仓库根目录仍保留原有可启动的演示版本。

- `Env/`、`lowlevel/`、`webapp/`：研究工作区的环境、底层控制器及网页程序。
- `experiments/`：训练、对比、延迟和本地分配等实验代码及其相关运行数据。
- `research_outputs/`：实验报告、配置、模型、checkpoint、评测和轨迹。最新分布式强化学习任务分配结果见 `research_outputs/local_allocator_mappo_20261103/`；历史底层训练见 `lowlevel_training_final/`，延迟实验见 `latency_manual_20261103/`。
- `docs/`：实施方案和研究设计，包含分布式本地任务分配器训练指南。
- `terrain_height.csv`：仿真地形数据。

归档保留实验失败和探索性结果；模型是否达到验收门槛应以各实验报告为准。当前策略及仿真协议与根目录演示版可能存在差异，使用时以对应实验配置、源码和模型哈希为准。

工作区中 `.venv` 是本机虚拟环境软链接，未上传；系统缓存、`__pycache__`、`node_modules` 和其他 `.git` 元数据未上传。历史说明所指向的**工作区外部**训练归档不在此快照中。部分历史脚本引用旧的 `远端机器文件夹` 路径；该目录在打包时不在当前工作区，不能保证这些脚本直接运行。原网页工作区存在的 API 凭据样式字符串在归档副本中已清空；请通过环境变量或运行时填写，不要提交凭据。

大批研究输出和训练轨迹会占用较多磁盘空间与下载时间。读取实验前建议先查看对应目录中的 `README.md`、报告、配置和验收文件，不要将所有模型和试验结果视为同一套设置。
