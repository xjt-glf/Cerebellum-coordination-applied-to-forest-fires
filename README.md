# 森林火场人机协同：大模型规划与强化学习执行

项目模拟森林火场中的无人机与地面人员协同。高层规划器分配任务；低层采用任务条件 MAPPO Actor 输出无人机动作；地面人员按任务选择作业点并使用现有寻路与灭火逻辑。提供网页可视化和启发式高层基线。

## 快速启动

推荐 Python 3.10–3.13，在项目根目录执行：

```bash
python3 -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
python webapp/server.py
```

浏览器打开 http://127.0.0.1:8000/ ，不要直接打开静态 HTML 文件。无需 GPU；默认使用启发式规划器，可先选择较少步数确认运行。

## 选择高层规划

- **启发式**：当前系统的高层基线，无人机动作仍由强化学习 Actor 输出。
- **大模型**：在前端填写服务商提供的 OpenAI 兼容 `base_url`、API Key 和模型名，再选择“大模型”。未提供密钥；请勿将自己的密钥提交到仓库。调用失败可能回退到启发式，具体见页面日志。完整环境输入可能产生较高 token 成本，可在界面关闭。
- **Codex 联合规划**：为外部 agent 设置的接口模式；该 agent 必须在每个高层窗口连接接口提交无人机和人员联合计划。单独选中此项不会自动调用 Codex，不接入外部 agent 时仿真会等待。

当前已有可视化的人机联合任务控制接口，人员指令需要通过现有几何通信覆盖才会生效，失联时保留旧任务；人员作业点选择、避障和移动复用环境逻辑。现有大模型 API 分支主要规划无人机；请勿将其误认为已实现完全自动的大模型人员规划。反馈归因模型与 RAG 尚未实现。

## 项目内容

- `Env/低层环境.py`：火场、无人机、人员、通信和补给仿真。
- `webapp/`：前端、仿真服务、人员控制器、高层规划和补给保护。
- `lowlevel/`：任务协议、观测构建、MAPPO Actor、训练和目标管理代码。
- `models/actor_selected.pt`：训练好的当前 Actor，SHA-256 `dfa5cdd0f4b673567c04220af9d82ee55f16920d55398a02471a0d535d59982e`。
- `terrain_height.csv`：仿真所需地形输入。

预训练模型为研究候选，人物任务在本地仿真中演示可运行，不能由此推断所有场景下都可靠；巡逻和执行能力存在局限。环境当前使用简化几何通信与瞬时地图共享，不是容量受限真实信道模型。网页“完整环境信息”选项包含真值，科研评测须明确观测边界。
